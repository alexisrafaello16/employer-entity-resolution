# Data & Confidentiality Notice

This public portfolio edition contains **no original private source dataset**.

- `data/sample/synthetic_employers.xlsx` is generated from fictional company names.
- `data/reference/` contains only synthetic seed entities and aliases.
- Aggregate benchmark figures in the README come from a larger private execution and are
  intentionally detached from source records. They are not expected to reproduce on the
  smaller public demo dataset.
- Generated `data/processed/`, `data/evaluation/`, and `output/` artifacts are ignored by Git.

Before using this code with organizational data, apply the organization's privacy, data
classification, retention, and access-control requirements.

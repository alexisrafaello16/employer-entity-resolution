# Examples

These files are compact, fictional illustrations for portfolio review. They are **not** extracts from the original private dataset.

- `employer_resolution_sample.csv`: human-readable examples of the problem and expected handling.
- `employer_master_sample.csv`: small synthetic master illustration.
- `alias_sample.csv`: synthetic alias relationships.

The authoritative generated pipeline artifacts are created locally under `data/processed/` and `output/`.
